### DESIGN BRIEF: Maple Street Bakery order page

  The client approved the five requirements below.
  The page you were given does not match all of them.

  1. Sidebar width.
     The sidebar should always take up exactly one-third of the page width,
     no matter how wide the browser window is.

  2. Header color.
     The header background should be a mid-tone gray, about halfway
     between black and white.

  3. Order button shape.
     The "Order Now" button in the product card should be exactly
     twice as wide as it is tall.

  4. Card size.
     The product card should be exactly 300 pixels wide in total,
     including its padding and border.

  5. Size field.
     The size field should only accept one of three fixed choices:
     Small, Medium, or Large.
